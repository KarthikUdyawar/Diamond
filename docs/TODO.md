## 📅 Day 2 — Feature Engineering Pipeline

### Data Validation

- [ ] 🔴 Validate column names, dtypes on raw CSV before processing
- [ ] 🔴 Raise a clear `ValueError` (not a pandas error) if validation fails

### Pre-Pipeline Cleaning (from notebooks 02 + 03)
- [ ] 🔴 Parse `Price` column — strip currency symbols, cast to float64
- [ ] 🔴 Parse `Messurements` column — split `"L x W x D"` → `length`, `width`, `depth_mm` floats
- [ ] 🔴 Remove outliers: length < 2, price > 20,000, weight > 3, depth_mm < 1
- [ ] 🔴 Remove duplicate rows (excluding Id column)

### Feature Transformations (adapted to Kaggle schema)
- [ ] 🔴 `OrdinalEncoder` for `Cut`: `["Fair", "Good", "Very Good", "Premium", "Ideal"]`
- [ ] 🔴 `OrdinalEncoder` for `Colour`: `["J", "I", "H", "G", "F", "E", "D"]`
- [ ] 🔴 `OrdinalEncoder` for `Clarity`: `["I1", "SI2", "SI1", "VS2", "VS1", "VVS2", "VVS1", "IF"]`
- [ ] 🔴 `OrdinalEncoder` for `Polish`: `["Fair", "Good", "Very Good", "Excellent", "Ideal"]`
- [ ] 🔴 `OrdinalEncoder` for `Symmetry`: `["Fair", "Good", "Very Good", "Excellent", "Ideal"]`
- [ ] 🔴 `OrdinalEncoder` for `Fluorescence`: `["Very Strong", "Strong", "Medium", "Faint", "None"]`
- [ ] 🔴 `OneHotEncoder` for `Shape` (nominal — no natural order)
- [ ] 🔴 `KNNImputer(n_neighbors=5)` for numerical columns
- [ ] 🔴 `SimpleImputer(strategy="most_frequent")` for categorical columns
- [ ] 🔴 Engineer `volume = length × width × depth_mm`
- [ ] 🔴 Engineer `carat_per_volume = weight / (volume + ε)`
- [ ] 🔴 Engineer `log_weight = log1p(weight)`
- [ ] 🔴 Remove `Price` from features (log-transform it as target vector separately)

### Pipeline Assembly
- [ ] 🔴 Wrap all transformations in a single `sklearn ColumnTransformer`
- [ ] 🔴 Fit pipeline **only on training data** — never the full dataset
- [ ] 🔴 `train_test_split(test_size=0.2, random_state=42)`
- [ ] 🔴 Save fitted pipeline as `data/processed/pipeline.joblib` via `joblib.dump`
