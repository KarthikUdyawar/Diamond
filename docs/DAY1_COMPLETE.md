## What Was Built

Replaced the old notebook-only project structure with a production-ready
monorepo layout. The old `containers/` Docker notebook setup was deleted.
All 4 Docker services (postgres, mlflow, api, ui) are defined with health
checks, startup ordering, and named volumes. A single `Makefile` covers
every operation so no one needs to remember raw `docker` commands.
Dependency management migrated from `dev-requirements.txt` to `pyproject.toml`
with uv and all versions pinned exactly.
